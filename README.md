# AI Lost & Found Retrieval System

An AI-powered Lost & Found system that helps users find lost items by matching uploaded images or descriptions with reported found items.

## Features
- Report lost or found items using images or text descriptions.
- AI-based image similarity matching using CLIP.
- Match items using descriptions and location.
- Display possible matches with similarity scores.
- Show found-item details and reporter contact information.

## Technologies Used
- Python
- Streamlit
- CLIP (AI image matching)
- Pillow and Requests

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run app.py

3. Open the local URL shown in the terminal.

## Applications
Useful for railway stations, colleges, public places, and other locations.

## Project Purpose
To make lost-item recovery easier through AI-based image and description matching.
